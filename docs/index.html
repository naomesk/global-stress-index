When does global stress peak?

One yearly index for 1959–2024 built from climate, mortality, disaster and pandemic data, then projected to 2100 under three climate scenarios. Three students, three modules, one report.

Read the reportTeam guideWord fileCode on GitHub

What we found

Periods (K-means, 3 groups)45 calm years, 15 stressed years, 6 crisis years.
Label spreadingStarted from 14 known years and recovered 88% of the labels of the other 52 years.
Peak so far2021, driven by the pandemic score. The early-1960s high comes from mortality and disasters; the long rise in climate stress is steady.
Scenarios to 2100Optimistic, baseline and pessimistic reach about 52, 87 and 122 points on the historical 0–100 scale. No scenario peaks before 2100.
First crisis-level yearAbout 2083 (baseline) and 2058 (pessimistic); not before 2100 in the optimistic scenario.
Forecast accuracyOn the 2016–2024 test years the trend and Random Forest models did not clearly beat naive guesses, because the test window holds the only pandemic.

This is a data-driven hypothesis, not a prediction of a real “end of the world.” The report lists its limits in the Discussion.

How the project fits together

Four domains, one score each

Climate (five indicators compressed by PCA), mortality, disasters and pandemic. Each is standardized so higher always means more stress, then averaged with equal weight.

One shared hand-off format

Every module writes the same two files, so the three members work in parallel and the integrator combines them with one command.

Reproducible

Settings live in one config file, the seed is fixed, and a test suite checks the pipeline. The team guide shows how to run it and how to bring in a module that does not follow the format.
